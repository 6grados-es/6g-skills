# 6g-skills

Skills de Claude de 6 Grados, instalables por el equipo y los clientes. Cada carpeta es una skill con su `SKILL.md`.

## Skills

| Carpeta | Qué hace |
|---|---|
| [`whatsapp-borrador/`](whatsapp-borrador/) | Deja un WhatsApp escrito y abierto en la aplicación, para que lo revises y lo envíes tú. No envía ni lee chats. |

## Cómo instalar una skill

Copia la carpeta de la skill dentro de la carpeta de skills de Claude:

- **Mac:** `~/.claude/skills/`
- **Windows:** `%USERPROFILE%\.claude\skills\`

Reinicia Claude. Para comprobarlo, pídele lo que dice su descripción (por ejemplo, «ábreme un WhatsApp para…»).

## Cómo añadir una skill

Una carpeta nueva con su `SKILL.md`. Sin datos personales de nadie: ni números, ni claves, ni nombres de clientes.
